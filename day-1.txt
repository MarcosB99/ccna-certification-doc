Network Fundamentals:

1.0 Explain the role and function of network components.
    1.1.a Routers
        A router is a networking device that receives, prioritizes, and forwards data packets between local devices and external networks like the internet. They are essentially the gateways between fifferent networks. They operate at Layer 3 (Network layer) of the OSI model.
        1.1.a.i Primary Function: Connect distinct IP subnets and determine the best path to send packets to their destination.
        1.1.a.ii Forwarding Decision: Based on the destination IP address using a Routing Table.
        1.1.a.iii CCNA Key Concept: Routers break bradcast domains. A broadcast packet (like an ARP request) sent on one interface will not be forwarded out another interface by default. Every router interface must belong to a different IP subnet.

    1.1.b Layer 2 and Layer 3 switches
        Is a hardware device that connects multiple computers, printers, and other wired devices together inside a LAN.
        1.1.b.i Layer 2 Switches (Data Link Layer):
            - Forward frames based entirely on destination MAC addresses.
            - Build and mantain a MAC address table by examining the source MAC address of incoming frames.
            - CCNA Key Concept: They break collision domains (each port is its own collision domain) but they do not break boradcast domains. All ports belong to the same broadcast domain unless separated by VLANs.
        1.1.b.ii Layer 3 Switches (Network Layer):
            - Often called Multilayer Switches, these perform MAC-based switching (Layer 2) and IP-based routing (Layer 3) in hardware.
            - CCNA Key Concept: They are heavily used for Inter-VLAN routing using Switch Virtual Interfaces (SVIs). They route packets between internal VLANs much faster than a traditional router.
    
    1.1.c Next-Generation Firewalls
        Traditional firewalls filter based on simple rules (IP addresses and port numbers). NGFWs go much deeper, operating up to Layer 7 (Application Layer).
            - NGFW: Can identify specific applications (e.g., distinguishing between regular web browsing and a BitTorrent client using the same port). They provide stateful inspection, URL filtering and malware protection.
            - IPS (Intrusion prevention system): Sits inline with traffic. It actively scans packets for known malware signatures or behavioral anomalies. If an attack is detected, the IPS drops the packet immediately.
            - CCNA key concept: The key distinction for the exam is that an IDS (Intrusion Detection System) only sends an alert, while an IPS actively blocks the threat.

0.0 What is a Network?
    A computer network is a digital telecommunications network which allows nodes to share resources.
    
    0.1 Client
        A client is a device that accesses a service made available by a server.
    0.2 Server
        A server is a device that provides functions or services for clients.
    
    The same device can be a client/server, depending on the situation.

    0.3 Switch
        A network switch is a hardware device that connects multiple devices together on a LAN using ethernet cables.
        - They have many network interfaces/ports for end hosts to connect to.
        - They provide connectivity to hosts within the same LAN.
        - They don't provide connectivity between LAN/s over the internet.
    
    0.4 Routers
        - They have fewer network interfaces than switches.
        - They provide connectivity between LANs.
        - They are therefore used to send data over the internet.

    0.5 Firewalls
        - They monitor and control network traffic based on configured rules.
        - They can be placed inside/outside the network.
        - They are known as "Next-Gen Firewalls" when they include more modern and advanced filtering capabilities.

        0.5.1 Types of Firewalls.
            -Network Firewalls: Hardware devices that filter traffic between networks.
            -Host-based firewalls: Software applications that filter traffic entering/exiting a host machine, like a PC.
